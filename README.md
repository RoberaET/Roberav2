## `[ 0x01 ] :: SYSTEM_OVERVIEW`

**Roberav2** departs from conventional portfolios. Instead of a passive document, it presents an interactive **Network Operations Center (NOC) and Core Router Dashboard** running live in the browser.

## `[ 0x03 ] :: PACKET TRACER & TOPOLOGY LABS`

The topology simulator showcases 3 enterprise-grade Cisco network architectures built and validated in Cisco Packet Tracer:

### 1. Daisy-Chain Multistory Topology
* **Architecture:** 4-floor vertical linear distribution switch stack.
* **Nodes & Edges:** 13 physical nodes spanning Core, Distribution, and Access layers.
* **Protocols:** VLAN segmentation (Data, Voice, Mgmt), Rapid STP (802.1w), Inter-VLAN routing.
* **Artifact:** Includes downloadable `DaisyChainLab.pkt` and comprehensive network documentation.

### 2. High-Availability Redundant Campus
* **Architecture:** Dual-Core collapsed spine with redundant distribution loops.
* **Nodes & Edges:** 13 active nodes with dual core router failover.
* **Protocols:** HSRP / VRRP first-hop redundancy, EtherChannel (LACP) trunk aggregation, OSPF multi-area routing.
* **Artifact:** Interactive failover node testing with downloadable `CampusNetworkLab.pkt`.

### 3. Multi-Branch Enterprise WAN
* **Architecture:** Enterprise HQ interconnected with dual remote branch offices over simulated WAN.
* **Nodes & Edges:** 16 nodes encompassing Edge Firewalls, Core Routers, and Branch Access switches.
* **Protocols:** IPSec site-to-site VPN tunnels, BGP route exchange, NAT/PAT, ACL security policies.
* **Artifact:** Downloadable `MultiBranchLab.pkt` with complete engineering schematics.

## `[ 0x06 ] :: LOCAL_DEPLOYMENT_GUIDE`

To bootstrap and run the portfolio locally on your workstation:

```bash
# 1. Clone the repository
git clone https://github.com/RoberaET/Roberav2.git

# 2. Navigate to project root
cd Roberav2

# 3. Install dependencies
npm install

# 4. Launch Vite development server
npm run dev
```

*Access the running portal at: `http://localhost:5173`.*

### Production Build
```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
